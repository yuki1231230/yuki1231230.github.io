Privacy Policy

Satoshi Auto Post · Last updated: November 23, 2026

Home Privacy Policy Terms of Service

Satoshi Auto Post ("the app") is a personal tool used only by its owner to publish the owner's own videos to the owner's own social media accounts. This policy explains what data the app uses.

Data the app accesses

  • YouTube (Google): the app requests only the youtube.upload permission, which it uses to upload videos to the owner's channel. It does not read, download, or analyze any other YouTube or Google data.
  • Instagram (Meta) and TikTok: the app uses the official content-publishing APIs to post videos to the owner's accounts. It does not read followers, messages, or other users' content.

How data is stored

Access tokens are stored as encrypted secrets in a private GitHub repository owned by the app's owner, and are used only to publish content. The app does not use a database and does not keep copies of any platform data.

Sharing

The app does not sell, share, or transfer any user data to third parties, and does not use data for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the Google Privacy Policy.

Revoking access

Access can be removed at any time from Google Account permissions, the Instagram "Apps and websites" settings, or TikTok's "Manage app permissions" settings.
